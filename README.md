# أذكاري | Azkari
مشروع Android مستقل بدون Replit.

## فتح المشروع
افتح مجلد المشروع في Android Studio ثم انتظر Gradle Sync واضغط Run.

## المزايا الحالية
- واجهة عربية RTL
- أذكار الصباح والمساء وبعد الصلاة والنوم
- سبحة إلكترونية
- يعمل محليًا بدون حساب أو خادم
- تصميم خفيف مناسب للموبايل

> النصوص الدينية تحتاج مراجعة علمية قبل النشر النهائي، ويمكن توسيع قاعدة الأذكار وإضافة المصادر والتكرارات والإشعارات في الإصدار التالي.
